# Native AI Lifeforms · 原生生灵

> 从脚本化 NPC，到会**自己商量、自己干活、出事了自己改计划**的数字同伴。

本仓库沉淀自两个可运行的 Windows 功能原型：

| 原型 | 引擎 | 演示内容 |
|---|---|---|
| **Monta · NPC 自主营地** | Unity | 两位同伴自主选址、语音协商分工、采集物资、捕获宠物、协同建成房屋；中途触发"同伴受伤""封锁采集目标"后自动改计划 |
| **QY · 第三人称开放场景** | Unreal Engine 5 | 第三人称视角下的连续探索与交互场景，作为原生生灵在高保真 3D 世界中的承载壳 |

两个原型共同验证了一个判断：**在不依赖大模型、不联网、不需要密钥的前提下，仅靠离线规则规划与协商，也能让多个 NPC 在 2 分钟内完成"目标 → 协商 → 分工执行 → 事件重规划 → 交付物"的完整闭环。** 这就是"AI 原生生灵"（Native AI Lifeform）的最小可行形态。

> ⚠️ 我们沿用原型作者的明确声明：**该原型不代表真实自我意识**。它是一个可工程化、可审计、可复现的自治智能体框架。

---

## 它解决了什么问题

传统游戏 / 虚拟世界里的 NPC：

- 是**脚本驱动**的——你走到 A 点触发 B 台词，作者没写到的地方就是空气墙；
- 是**单人单次**的——NPC 之间不会真的"商量"，所谓对话都是预先排好的；
- 是**反应式**的——玩家推一下动一下，世界事件来了要么无视、要么硬切镜头。

而 LLM-based agent（如 Generative Agents、Voyager）虽然灵活，但存在推理成本高、延迟高、行为不可预测、难审计、难上线生产环境的问题。

**Native AI Lifeforms 走第三条路**：用结构化的目标图 + BDI 信念-愿望-意图 + 多智能体协商协议 + 事件驱动重规划，让 NPC 在毫秒级、确定性、可离线的前提下表现出"自主性"；并在需要开放性对话、创造性决策时，通过**可插拔适配器**接入 LLM。

## 核心能力

```
┌─────────────────────────────────────────────────────────┐
│                    Perception / 感知                     │
│        世界状态、队友状态、资源、事件、玩家行为            │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│              Belief–Desire–Intention (BDI)               │
│  信念 B  │ 愿望 D(长期目标: 建成营地) │ 意图 I(当前任务)   │
└────────────────────────┬────────────────────────────────┘
                         ▼
┌──────────────┬──────────────┬───────────────────────────┐
│  Goal Graph  │  Negotiation │   Event-driven Replanning │
│  目标分解    │  多智能体协商 │   事件驱动重规划           │
│  房屋=墙+顶  │  谁采集谁建造 │   受伤/封锁→撤销→重排      │
└──────────────┴──────────────┴───────────────────────────┘
                         ▼
┌─────────────────────────────────────────────────────────┐
│              Skill Library / 技能原子动作                 │
│   移动·采集·建造·捕宠·休养·分享·警戒·语音播报             │
└─────────────────────────────────────────────────────────┘
```

- **目标分解（Goal Decomposition）**：把"建成营地"拆成"选址→采集木材→采集石材→砌墙→上顶→捕宠→入住"，每个节点有前置条件与后置效果（STRIPS-like）。
- **多智能体协商（Negotiation）**：开场 ~20 秒内，两个 agent 通过提案-反提案-确认协议就分工达成一致，并以中文语音播报（离线 TTS，无需联网）。
- **事件重规划（Replanning）**：世界事件（同伴 HP 归零、资源点被封锁）触发当前意图撤销、目标图重算、分工重谈，全过程 < 1 秒。
- **LLM 可插拔**：核心规划零 LLM 调用；仅在开放对话、即兴表演、动态剧情分支处通过 `LLMAdapter` 接云端或本地模型。

## 快速开始

```bash
git clone https://github.com/leslie520-bye/native-ai-lifeforms.git
cd native-ai-lifeforms
pip install -r requirements.txt
python -m examples.camp_demo
```

你会在终端里看到两个 agent（`Aki`、`Ren`）：

1. 互相协商分工（谁去采集木材、谁去采石、谁先搭框架）；
2. 并行执行采集与建造；
3. 中途注入 `injury` / `resource_blocked` 事件，观察它们撤销旧任务、重谈分工、回到休养点再复工。

命令行 demo 与 Windows 原型演示的是**同一套状态机与规划协议**，只是渲染层从游戏引擎换成了 stdout。

## 设计哲学

1. **先确定性，后概率性。** 能离线规则搞定的，绝不调用大模型。
2. **可审计优先于智能。** 每个 NPC 每一步在干什么、为什么，都能被人类看懂、被日志回放。
3. **不假装意识。** 我们造的是**行为上像活物的自治系统**，不是有意识的主体。论文与方案中明确区分这两者。
4. **引擎中立。** 大脑（Python 参考实现）与身体（Unity / UE5 / Web / 数字人）通过标准消息协议解耦。
